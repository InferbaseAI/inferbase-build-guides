# Inferbase quickstarts

Small, complete applications built on [Inferbase](https://inferbase.ai), the OpenAI-compatible API
that routes every request to the best model for it, on quality, cost and latency, and explains
each decision. Each one runs with an Inferbase API key and `npm run dev`, and is meant to be copied.

| Quickstart | What it is |
|---|---|
| [customer-support-agent](./customer-support-agent) | A support chat that answers from your docs with sources, hands off to a person, and shows the routing receipt under every answer. Embeds on any site with one script tag. |
